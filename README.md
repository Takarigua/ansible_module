# yandex_cloud_elk Collection

## Overview

`yandex_cloud_elk` — это Ansible Collection, содержащая кастомный модуль `my_own_module`, который создаёт текстовый файл с заданным содержимым на удалённом хосте.

Коллекция также включает роль `create_file`, использующую этот модуль.

## Contents

- Модуль: `my_own_module`
- Роль: `create_file`
